# 開発ツール — 閲覧専用ビューアの作り直し

メイン（このリポジトリの `index.html`）から、設計事務所・市に見せる
**閲覧専用ビューア**（`antenna_viewer` の `index.html`）を作り直すための道具です。

## ファイルと役割

| ファイル | 役割 |
| --- | --- |
| `index.html`（このリポジトリの直下） | メイン。積算・図面作成ツール本体。**編集するのはここ** |
| `開発ツール/viewer-block.html` | 「隠す・止める」処理の**編集元**（CSS ＋ JS） |
| `開発ツール/台帳埋込.py` | `受付台帳.html` をメインの中へ入れる道具（下の「受付台帳のひな型」を見てください） |
| `開発ツール/ビューア生成.ps1` | メインからビューアを作り直すスクリプト（普段使うのはこれ） |
| `開発ツール/ビューア生成.py` | 上と同じことをする Python 版（PowerShell が無い環境・自動チェック用） |
| `antenna_viewer/index.html` | 閲覧専用ビューア本体。**自動生成物・直接編集禁止** |

## 使い方

**メインを更新したら毎回これを実行してください。**
実行しないとビューアが古いままになります。

```
powershell -ExecutionPolicy Bypass -File "J:\Dropbox\仕事\アンテナ取付工事\開発ツール\ビューア生成.ps1"
```

作り直した `index.html` を `antenna_viewer` に反映（アップロード）すれば完了です。

### ビューアが最新かどうか確かめるだけ（書き込まない）

```
powershell -ExecutionPolicy Bypass -File "…\開発ツール\ビューア生成.ps1" -Check
```

終了コード … `0` = 最新 ／ `2` = 古い（作り直しが必要） ／ `1` = エラー

### 場所を自分で指定したいとき

| PowerShell | Python | 意味 |
| --- | --- | --- |
| `-MainPath` | `--main` | メイン `index.html` の場所 |
| `-BlockPath` | `--block` | `viewer-block.html` の場所 |
| `-OutPath` | `--out` | 書き出すビューア `index.html` の場所 |
| `-Check` | `--check` | 比べるだけ（書き込まない） |

指定しない場合は、`開発ツール` の置かれた場所から
`ソフトウェア／ソフトウェア_ビューア`（＝ `antenna_main／antenna_viewer`）の
並びを探します。見つからなければエラーで止まります。

PowerShell が無い環境（Linux・CI・クラウド上の作業）では Python 版を使えます。

```
python3 開発ツール/ビューア生成.py            # 作り直す
python3 開発ツール/ビューア生成.py --check    # 比べるだけ
```

## 受付台帳のひな型（台帳埋込.py）

メインの 📒受付台帳 →「🌐 HTML」は、受付台帳ソフト（`受付台帳.html`）に台帳の中身を
差し込んだ 1 枚の HTML を書き出します。そのひな型は**メイン自身が持っています**。
持たせてあるので、書き出すときにファイルを選ばずに済みます（Excel 書き出しと同じで、押すだけ）。

**`受付台帳.html` を直したら、毎回これを実行してください。**
実行しないと、書き出される HTML が古いままになります。

```
python3 開発ツール/台帳埋込.py            入れ直す
python3 開発ツール/台帳埋込.py --check    比べるだけ（最新=0 / 古い=2）
```

入れ直したあとは、**ビューアも作り直してください**（メインが変わるため）。

`受付台帳.html` は base64 にして
`<!-- ==受付台帳テンプレート START … == -->` と `END` の間へ入れています。
そのまま入れると、`受付台帳.html` の中の `<html>` や `</head>` の行が
ビューア生成の目印（「`</head>` の行はちょうど 1 つ」等）とぶつかり、
ビューアを作れなくなるためです。

## 何をしているか

メインをそのままコピーし、決まった **5 か所** に手を入れるだけです。
本体のコードは 1 行も書き換えません。だから表示・計算・印刷はメインと同じで、
「隠す・止める」だけが `viewer-block.html` に集まります。

| # | 場所 | 入れるもの |
| --- | --- | --- |
| 1 | `<html>` の直前 | 自動生成の断り書き |
| 2 | `<title>` の行 | 「アンテナ工事 図面・物件ビューア（閲覧専用）」に差し替え |
| 3 | `</head>` の直前 | `viewer-block.html` の **STYLE**（入力・保存・編集まわりの UI を隠す CSS） |
| 4 | 地図の `onStagePointerDown()` の冒頭 | `viewer-block.html` の **MAP-POINTERDOWN**（作図・移動を止めて「クリック＝選択／ドラッグ＝パン」に固定） |
| 5 | `</body>` の直前 | `viewer-block.html` の **SCRIPT**（保存・同期・バックアップの停止、ビューアのホーム画面 など） |

生成物には `==VIEWER-MODE … ==` という目印が入るので、
ビューアのどこが追加分なのかは見れば分かります。

## 閲覧専用まわりを変えたいとき

1. `開発ツール/viewer-block.html` を直す（**ビューアの `index.html` は直さない**）
2. `ビューア生成.ps1` を実行する
3. 出来た `index.html` を `antenna_viewer` に反映する

`viewer-block.html` の中の
`<!-- ==BLOCK … START== -->` / `<!-- ==BLOCK … END== -->` の行は
生成スクリプトの目印です。消したり書き換えたりしないでください。

## エラーで止まったとき

差し込む場所（目印）が見つからないと、**何も書かずにエラーで止まります**。
古いビューアが黙って残るより、止まって気づけるほうが安全なためです。

よくある原因と直しかた。

| メッセージ | 原因 | 直しかた |
| --- | --- | --- |
| 目印『…』が 0 件でした | メイン側の作りが変わった | スクリプト内の目印（正規表現）を今のメインに合わせる |
| 地図の差し込み位置が変わっています | `onStagePointerDown()` の 1 行目が変わった | メインを見て、スクリプトの目印を直す |
| すでに生成済みのビューアのようです | メインとしてビューアを指定した | `-MainPath` を見直す |
| `viewer-block.html` に『…』の行がありません | 目印の行を消してしまった | `<!-- ==BLOCK … START== -->` などを戻す |

とくに **4 番（地図）** は、止まらずに通してしまうと
「作図・移動ができてしまう閲覧専用ビューア」が出来てしまうため、
必ず確認してから差し込むようにしてあります。

## 決めごと

- 出力は **UTF-8（BOM なし）**、改行は **CRLF**。差し込んだブロックの中だけ LF です
  （今あるビューアと同じ並びに揃えてあります）。
- `ビューア生成.ps1` は **UTF-8（BOM 付き）** で保存してください。
  Windows PowerShell 5.1 は BOM が無いと日本語を読み違えます。
- `ビューア生成.ps1` と `ビューア生成.py` は**同じ結果**（1 バイトも違わない）になります。
  片方だけ直すと差が出るので、変えるときは両方を直してください。
- 今のメインから作り直すと、今の `antenna_viewer/index.html` と
  **1 バイトも違わないものが出来る**ことを確認済みです。
